# 🎨 Frontend Project

This is a 🖥️ TTT frontend project built using **Next.js** with various 📚 libraries and 🛠️ tools for enhanced development and 🧑‍💻 user experience. The project structure is designed to be 📈 scalable and maintainable.

---

## ✨ Features

- **⚛️ React and Next.js** for building a robust and modern frontend application.
- **🎨 Material-UI (MUI)** for sleek and responsive UI components.
- **🛠️ Redux Toolkit** for efficient state management.
- **📄 React-PDF-Viewer** for PDF viewing capabilities.
- **📝 Formik and Yup** for form handling and validation.
- **📊 ApexCharts** for interactive data visualizations.
- **🎨 Tailwind CSS** for utility-first styling.
- **🧪 Jest and Testing Library** for testing components and functionality.

---

## ⚙️ Installation

1. 🌀 Clone the repository:

   ```bash
   git clone <repository-url>
   cd frontend
   ```

2. 📦 Install dependencies:

   ```bash
   npm install
   ```

---

## 📜 Scripts

- `npm run dev`: 🚀 Start the development server.
- `npm run build`: 🏗️ Build the project for production.
- `npm run start`: 🛡️ Start the production server.
- `npm run lint`: 🔍 Run linting checks.
- `npm run test`: 🧪 Run unit tests.

## 📂 Folder Structure

```
frontend/
├── src/                # Main source folder
│   ├── 🧩 components/   # Reusable React components
│   ├── 📄 app/          # Next.js pages
│   ├── 🎨 styles/       # Global styles
│   ├── 🛠️ redux/        # Redux store and state management
│   ├── 📌 constants/    # Constants and configuration
│   ├── 📌 hooks/        # custom hooks file
│   ├── 🛠️ utils/        # Utility functions
│   └── 🧪 __mocks__/    # Unit and integration tests
├── 🖼️ public/           # Static assets
└── package.json         # Project metadata and script
```

## 🔑 Key Libraries

### Dependencies

## 🛠️ Development Workflow

1. 🚀 Start the development server:

   ```bash
   npm run dev
   ```

2. 🌐 Access the app at `http://localhost:3000`.

3. ✍️ Make changes and commit your code following best practices.

4. 🔍 Run lint checks before pushing changes:

   ```bash
   npm run lint
   ```

5. 🧪 Run tests to ensure quality:

   ```bash
   npm run test
   ```

## 🧪 Testing

Testing is set up using **🧪 Jest** and **🧪 React Testing Library**.

To run tests:

```bash
npm run test
```

Add test files inside the `tests/` folder or alongside components with the `.test.tsx` or `.test.js` extension.
